🧩 Интерактив: сложение по правилу параллелограмма

Потяните ползунки коэффициентов k и m, чтобы увидеть, как вектор p = k·a + m·b раскладывается по векторам a и b.

1 1

p = 1·a + 1·b

📝 Алгоритм разложения вектора

  1. Отложить все три вектора от одной точки.
  2. Достроить до параллелограмма (или треугольника).
  3. Вычислить значения коэффициентов k и m для каждого вектора.
  4. Записать разложение: p = k·a + m·b.

Пример с презентации:

p = 3·a + 0,5·b (вектор p — диагональ параллелограмма)

p = -4·a + 1,5·b (отрицательный коэффициент меняет направление)
